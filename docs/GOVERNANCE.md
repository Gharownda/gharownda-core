# Governance

This repository is public and reusable-first.

A change belongs here only when it can be explained, tested, and maintained without relying on private Gharownda product details. Product-specific implementation remains in the private application repository.

Maintainers decide extraction boundaries, architecture, releases, security-sensitive behavior, and governance. Automated contributors operate only on explicitly bounded implementation tasks and do not approve or merge their own work.

Public examples and tests use synthetic data only.
