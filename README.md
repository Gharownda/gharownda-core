# Gharownda Core

Gharownda Core is the public open-source home for reusable building blocks used by the Gharownda ecosystem.

The repository follows an extraction rule: components belong here when they have a genuine reusable boundary and can be documented and tested independently.

Potential areas include generic provenance/linking primitives, provider-neutral interfaces, reusable policy helpers, and other cross-project utilities.

## Current status

Foundation only. No speculative framework has been created yet.
